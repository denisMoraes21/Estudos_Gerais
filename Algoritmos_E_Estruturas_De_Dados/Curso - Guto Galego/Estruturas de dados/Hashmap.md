# Hashmap

* Chave-valor
* Complexidade O(1)
* Se fosse array de tuplas, complexidade seria O(n), pois tem que percorrer um a um, conforme esse array cresce.
* Load Factor: diferença entre quantidade de dados e estrutura de dados.
* Collisions: tentar alocar uma informação onde já existe, valor passa para o próximo disponível
* Itens que colidem, sublista de dados.

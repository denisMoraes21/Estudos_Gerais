### Linked List

* Não estão sequencialmente em memória. São só referências;
* Vantagens e desvantagens: leitura mais rápida para Array (O(1)), só precisa saber o início e a posição, Linked List (O(n)); Read para Linked List - melhor caso O(1) e pior caso (O(n)); Insert para Linked List - melhor caso (O(1)) e para pior caso (O(n)); Delete (O(1)) e para pior caso O(n).

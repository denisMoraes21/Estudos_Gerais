
\begin{frame}{Flip Flop JK - Mestre escravo}
    Quando o clock fica em nível alto:
    \begin{itemize}
        \item O mestre fica habilitado;
        \item O mestre observa as entradas \(J\) e \(K\);
        \item O escravo fica bloqueado;
        \item A saída externa \(Q\) ainda não muda.
    \end{itemize}
    Quando ocorre a borda de descida:
    \begin{itemize}
        \item O mestre é bloqueado;
        \item O escravo é habilitado;
        \item O estado armazenado no mestre é transferido para o escravo;
        \item A saída \(Q\) é atualizada.
    \end{itemize}
\end{frame}

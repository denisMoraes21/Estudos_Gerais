\item \textbf{Aplicação industrial: contador de peças}

Um sensor gera um pulso sempre que uma peça passa por uma esteira. Deseja-se
mostrar no display a quantidade de peças, de 0 até 7.

\begin{enumerate}[label=\alph*)]
    \item Quantos flip-flops são necessários para representar os valores de
    0 até 7? Justifique.
    \item Qual dispositivo deve receber os pulsos do sensor?
    \item Qual será o valor binário mostrado depois da passagem de cinco peças?
\end{enumerate}

\item \textbf{Aplicação industrial: ligar e desligar um motor}

Um botão $L$ deve ligar um motor e um botão $D$ deve desligá-lo. O estado do
motor deve permanecer armazenado depois que o botão for solto.

\begin{enumerate}[label=\alph*)]
    \item Por que um circuito puramente combinacional não é suficiente?
    \item Qual elemento de memória pode ser utilizado nessa aplicação?
    \item Em um latch SR com portas NOR, a qual entrada deve ser ligado o botão
    de ligar? E o botão de desligar?
\end{enumerate}

\item \textbf{Desafio: contador com display de 7 segmentos}

\begin{enumerate}[label=\alph*)]
    \item Quantos bits são necessários para representar os números de 0 a 9?
    \item Quantos flip-flops são necessários para armazenar esses bits?
    \item Depois de qual estado o contador deve retornar para $0000$?
    \item Qual é a função do decodificador BCD para 7 segmentos?

\begin{frame}{Código ASCII: Exemplo}
    \small

    Vamos representar a palavra:

    \[
        \text{ABC}
    \]

    Os códigos ASCII são:

    \[
        A = 65_{10} = 01000001_2
    \]

    \[
        B = 66_{10} = 01000010_2
    \]

    \[
        C = 67_{10} = 01000011_2
    \]

    Portanto:

    \[
        \boxed{
        ABC =
        01000001\
        01000010\
        01000011
        }
    \]

\end{frame}

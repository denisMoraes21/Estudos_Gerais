\begin{frame}{Conversão de Binário para Gray}
    \small
    Para converter um número binário em Gray:

    \begin{enumerate}
        \item O bit mais significativo é mantido;
        \item Os demais bits são obtidos através de operações XOR
        entre bits adjacentes.
    \end{enumerate}
    Para:
    \[
        B = B_3B_2B_1B_0
    \]
    temos:
    \[
        G_3 = B_3
    \]
    \[
        G_2 = B_3 \oplus B_2
    \]
    \[
        G_1 = B_2 \oplus B_1
    \]
    \[
        G_0 = B_1 \oplus B_0
    \]
\end{frame}

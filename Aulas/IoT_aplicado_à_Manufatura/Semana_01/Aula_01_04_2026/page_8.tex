    Volume e criticidade de dados:
    \begin{itemize}
        \item Riscos: muitos sensores, coleta contínua, alta frequência
        \item Alto volume: armazenamento, rede sobrecarregada, latência, processamento pesado
        \item Edge coputing
        \item Filtragem de dados (imagem vs. dados)
        \item Compressão de dados
        \item Persistência de dados
    \end{itemize}

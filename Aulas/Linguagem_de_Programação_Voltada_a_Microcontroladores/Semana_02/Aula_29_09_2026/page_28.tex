\begin{frame}{Síntese — Uma função precisa de uma interface clara}
\begin{itemize}
\item Parâmetros descrevem entradas; retorno descreve o resultado.
\item C usa passagem por valor, inclusive para ponteiros.
\item Vetores exigem contrato de tamanho e acesso válido.
\item Cabeçalhos declaram interfaces; arquivos \texttt{.c} as implementam.
\item Recursão exige caso-base, progresso e análise da pilha.
\end{itemize}

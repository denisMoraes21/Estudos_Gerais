\begin{frame}{Exercícios independentes}
\small
\begin{enumerate}
\item Escolha tipos para: quantidade de peças; temperatura de $-2{,}5\,^\circ$C; setor C; presença de uma peça. Justifique.
\item Faça o rastreamento: \texttt{int a = 7; int b = a; a = 9; b = 4;}. Quais são os valores finais?
\item Escreva um programa que declare \texttt{pecas = 120}, \texttt{tensao\_v = 3.3}, \texttt{setor = 'C'} e \texttt{pronto = true}; exiba cada valor com seu rótulo.
\item Corrija e explique: \texttt{double t = 21,5;}, \texttt{char s = "B";} e \texttt{int n; printf("\%d", n);}.
\end{enumerate}
\begin{block}{Entrega}
Respostas dos itens 1, 2 e 4; arquivo C do item 3 e sua saída. Consulte o gabarito após a tentativa.
\end{block}
\end{frame}

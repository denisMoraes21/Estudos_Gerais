\begin{frame}[t]{Pseudocódigo: expressar a solução}
\begin{itemize}
\item Texto estruturado que descreve um algoritmo.
\item Usa palavras como LER, SE, ENTÃO e ESCREVER.
\item Não depende de uma linguagem específica.
\item Não existe uma única sintaxe universal; a convenção deve ser clara.
\end{itemize}
\begin{block}{Convenção destas aulas}
Usaremos $\leftarrow$ para atribuir um valor e recuo para mostrar os comandos que pertencem à mesma decisão ou repetição.
\end{block}
\end{frame}

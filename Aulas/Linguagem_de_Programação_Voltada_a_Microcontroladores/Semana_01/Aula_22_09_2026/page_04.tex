\begin{frame}[t]{O que é lógica de programação?}
\begin{itemize}
\item Organizar instruções e decisões para resolver um problema.
\item Relacionar causas e consequências: se a condição ocorre, qual ação é executada?
\item Verificar se a solução atende à regra para diferentes entradas.
\item Separar a intenção do programa da linguagem usada para escrevê-lo.
\end{itemize}
\begin{exampleblock}{Raciocínio}
Temperatura = 30. A condição ``maior ou igual a 30'' é verdadeira. Logo, o sinalizador deve ligar.
\end{exampleblock}
\end{frame}

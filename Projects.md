# 🚀 1. Sistema de Detecção de Padrões Financeiros com C++ + IA

### 🔥 Stack

* C++
* SQLite ou PostgreSQL
* API REST (Boost.Beast ou Pistache)
* ONNX Runtime (para rodar modelo de IA treinado em Python)
* Docker

### 💡 Ideia

Um sistema que:

1. Consome dados de mercado (ex: Binance API)
2. Armazena histórico no banco
3. Detecta padrões gráficos automaticamente (triângulo, rompimento, etc.)
4. Usa modelo de IA para classificar probabilidade de alta/queda
5. Expõe API REST com sinais

### 🎯 Por que isso é forte?

* Mostra domínio de:

  * Performance em C++
  * Persistência de dados
  * Integração com IA
  * Arquitetura modular
* Conecta com seu interesse em padrões gráficos

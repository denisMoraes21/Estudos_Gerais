    Problema da Parada (Halting Problem):
    \begin{columns}
        \column{0.5\textwidth}
        \begin{itemize}
            \item \textbf{Pergunta:} "Dado um programa qualquer e uma entrada, é possível saber sempre se esse programa vai parar ou rodar para sempre?"
            \item \textbf{Resposta:} "Não existe um algoritmo geral que resolva isso para todos os casos."
        \end{itemize}

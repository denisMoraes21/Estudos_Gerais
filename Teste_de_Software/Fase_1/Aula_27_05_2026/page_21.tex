\begin{frame}{Conceitos fundamentais sobre Testes de Software}
    Falha:
    \begin{itemize}
        \item É quando o sistema se comporta de forma incorreta em execução.
        \item É o efeito visível para o usuário (VOC).
        \item Só acontece quando o defeito é ativado.
        \item \textbf{Exemplo:} O sistema retorna valor errado ou trava ao executar (desastre).
    \end{itemize}
\end{frame}

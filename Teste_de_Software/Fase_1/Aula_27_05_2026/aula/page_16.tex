\begin{frame}{Conceitos fundamentais sobre Testes de Software}
    Verificação:
    \begin{itemize}
        \item \textbf{Pergunta-chave:}  “Estamos construindo o produto certo da forma certa?”
        \item \textbf{Foco:} processo e conformidade com especificações
        \item Não necessária a execução de código.
        \item \textbf{Atividades típicas:} revisão de código, inspeção de documentos, análise estática.
        \item \textbf{Exemplo:} verificar se uma função foi implementada conforme o requisito técnico.
    \end{itemize}
\end{frame}

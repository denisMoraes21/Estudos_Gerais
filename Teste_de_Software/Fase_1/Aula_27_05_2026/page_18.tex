\begin{frame}{Conceitos fundamentais sobre Testes de Software}
    Teste de Software:
    \begin{itemize}
        \item \textbf{Pergunta-chave:}  O sistema funciona corretamente?”
        \item \textbf{Foco:} detectar defeitos
        \item Consiste em executar o software para encontrar erros.
        \item \textbf{Atividades típicas:} teste unitário, de integração, de sistema, de aceitação;
        \item \textbf{Exemplo:} executar casos de teste e verificar se a saída está correta.
    \end{itemize}
\end{frame}

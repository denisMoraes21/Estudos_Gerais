\begin{frame}{Reporte de bugs}
    Objetivo:
    \begin{itemize}
        \item Um bug report existe para transformar uma observação de erro em uma informação técnica útil para correção.
        \item Permitir a reprodução do defeito.
        \item Apoiar a correção pelo desenvolvedor.
        \item Permitir priorização correta.
        \item Servir como evidência do problema.
        \item Garantir rastreabilidade no processo de qualidade.
    \end{itemize}
\end{frame}

\begin{frame}{Conceitos fundamentais sobre Testes de Software}
    Validação:
    \begin{itemize}
        \item \textbf{Pergunta-chave:}  “Estamos construindo o produto certo?”
        \item \textbf{Foco:} necessidade do usuário / valor entregue
        \item Garante que o software atende às expectativas reais do usuário.
        \item Envolve execução do sistema.
        \item Mais ligada ao uso prático
        \item \textbf{Exemplo:} o sistema resolve o problema do usuário na prática?
    \end{itemize}
\end{frame}

\begin{frame}{Conceitos fundamentais sobre Testes de Software}
    Defeito:
    \begin{itemize}
        \item É o problema no código ou artefato causado por um erro.
        \item Está no software (código, design, documentação)
        \item Pode ou não se manifestar em execução.
        \item \textbf{Exemplo:} Uma condição if escrita errado no código.
    \end{itemize}
\end{frame}
